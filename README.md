# 💨 VAYU-NCR: 72-Hour Air Quality & Inversion Forecasting

VAYU-NCR is a Streamlit-based prototype designed to simulate air-quality forecasting and pollution-risk assessment across major NCR regions.

The dashboard allows users to adjust environmental and pollution-related inputs and observe how they affect simulated AQI trends and policy advisories.

## 🚀 Features

- 📍 Select an NCR region:
  - Delhi Central
  - Noida
  - Gurugram
  - Ghaziabad
  - Faridabad

- 🌡️ Adjust temperature

- 💨 Adjust wind speed

- 🔥 Enter stubble-fire hotspot count

- 📊 Display dynamic environmental metrics

- ⚠️ Generate GRAP-based policy advisories based on simulation inputs

- 📈 Visualize a simulated 72-hour AQI trend

- 🧮 Calculate a simplified boundary-layer-height indicator

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
